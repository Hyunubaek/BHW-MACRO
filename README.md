# BHW MACRO

PowerPoint 매크로 모음(BHW 매크로) 배포 저장소입니다.

## 설치
1. PowerPoint 를 모두 닫습니다.
2. [PPT_Macro_Setup.exe](https://github.com/Hyunubaek/BHW-MACRO/raw/main/install/PPT_Macro_Setup.exe) 를 받아 실행합니다.
   (Windows 보호 창이 나오면 [추가 정보] -> [실행])
3. PowerPoint 를 켜면 홈 오른쪽에 [BHW 매크로] 탭이 생깁니다.

## 업데이트
설치 후에는 따로 받을 필요가 없습니다. PowerPoint 를 켤 때 하루 한 번 새 버전을 확인해 받아 두고,
다음에 PowerPoint 를 켜면 적용됩니다. (메뉴 > 설정 > 업데이트 확인 에서 바로 확인하거나 자동 확인을 끌 수 있습니다.)

## 제거
[PPT_Macro_Remove.exe](https://github.com/Hyunubaek/BHW-MACRO/raw/main/install/PPT_Macro_Remove.exe) 를 실행합니다.
